# Tradedesk

Stock research by Eric H: a trade desk of buy, wait, hold and avoid calls with price targets and stop losses, upcoming events, a weekly macro read with a daily briefing, and a blog.

Static HTML, CSS and JS with no build step. All data lives in `data.js` (stocks and blog posts) and `macro.js` (macro read and briefing).

Run locally:

```sh
python3 -m http.server 5177
```

Not investment advice. All figures are illustrative.
